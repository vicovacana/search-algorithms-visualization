A* algortihm

A* is an informed search algorithm, or a heuristic search.

The "intelligence" of A* comes from its cost function. For every node n in the search space, A* calculates a total cost f(n):

f(n) = g(n) + h(n)

The Components:

  • g(n) (Actual Cost): This represents the exact cost of the path from the starting node to the current node n. As the algorithm moves further from the start, g(n) increases.
  • h(n) (Heuristic Cost): This is the "estimated" cost from node n to the goal. This is where the algorithm "guesses" the remaining distance. Because it's a guess, we call it a heuristic.
  • f(n) (Total Estimated Cost): This is the sum of both. A* always chooses to expand the node with the lowest f(n) value first.

For a 2D grid you can calculate h(n) with Manhattan Distance:

h(n)=|x(goal)-x(n)|+|y(goal)-y(n)|

How to Solve a Maze Using the A* Strategy

If you want to navigate the maze like the algorithm, follow this step-by-step logic to find the shortest path:

  • 1. Check your surroundings: Look at all adjacent cells (up, down, left, right) that aren't walls.
  • 2. Calculate the F-score: For each cell, add the steps you've already taken (g) to the estimated distance to the exit (h).
  • 3. Use the Manhattan Rule: To quickly guess the distance (h), simply count how many squares horizontal and vertical you are away from the red target.
  • 4. Pick the lowest value: Always move to the square with the smallest f(n). This ensures you are always moving towards the goal efficiently.
  • 5. Manage the "Open List": If you hit a dead end, go back to the last junction where you had another "candidate" square with a low score and continue from there.

Pro Tip: A* is optimal because it never overestimates the distance. It’s a perfect balance between experience (distance covered) and vision (distance remaining).

Breadth-First Search (BFS)

BFS is an uninformed or "blind" search algorithm. Unlike A*, it has no heuristic to guide it towards the goal.

The core mechanism of BFS is that it explores the search space level by level. It visits all direct neighbors of the starting node first, then all their neighbors, and so on.

The Components:

  • Queue (FIFO): BFS relies on a First-In-First-Out data structure. Nodes discovered first are explored first. This guarantees that paths are checked in order of their length.
  • Visited Set: To avoid infinite loops, BFS keeps track of every node it has already explored so it never visits the same cell twice.
  • The Wave Effect: Because of how the Queue works, the algorithm spreads outwards from the starting point equally in all directions, much like a ripple in a pond.

Shortest Path Guarantee: In an unweighted grid (where every step costs 1, like our maze), BFS is guaranteed to find the shortest possible path to the goal.

How to Solve a Maze Using the BFS Strategy

If you want to navigate the maze like a BFS algorithm, follow this step-by-step logic:

  • 1. Check your surroundings: Identify every valid move (up, down, left, right) from your current position.
  • 2. Take one step everywhere: Imagine you can split yourself into multiple clones. Send one clone into every available adjacent square simultaneously.
  • 3. Wait for all clones: Do not let any single clone take a second step until every other clone has taken their first step.
  • 4. Expand the perimeter: Now, let every clone take exactly one more step into a new, unvisited square. Repeat this process level by level.
  • 5. First to the finish line: Because all paths are explored at the exact same pace, the very first "clone" that touches the goal has mathematically found the shortest route.

Pro Tip: BFS is reliable but memory-heavy. Because it explores everywhere equally instead of moving toward a specific target, it can be very slow in large, open spaces.
