A* algortihm

A* is an informed search algorithm, or a heuristic search.

The "intelligence" of A* comes from its cost function. For every node n in the search space, A* calculates a total cost f(n):

f(n) = g(n) + h(n)

The Components:

  • g(n) (Actual Cost): This represents the exact cost of the path from the starting node to the current node n. As the algorithm moves further from the start, g(n) increases.
  • h(n) (Heuristic Cost): This is the "estimated" cost from node n to the goal. This is where the algorithm "guesses" the remaining distance. Because it's a guess, we call it a heuristic.
  • f(n) (Total Estimated Cost): This is the sum of both. A* always chooses to expand the node with the lowest f(n) value first.

For a 2D grid you can calculate h(n) with Manhattan Distance:

h(n)=|x(goal)-x(n)|+|y(goal)-y(n)|

How to Solve a Maze Using the A* Strategy

If you want to navigate the maze like the algorithm, follow this step-by-step logic to find the shortest path:

  • 1. Check your surroundings: Look at all adjacent cells (up, down, left, right) that aren't walls.
  • 2. Calculate the F-score: For each cell, add the steps you've already taken (g) to the estimated distance to the exit (h).
  • 3. Use the Manhattan Rule: To quickly guess the distance (h), simply count how many squares horizontal and vertical you are away from the red target.
  • 4. Pick the lowest value: Always move to the square with the smallest f(n). This ensures you are always moving towards the goal efficiently.
  • 5. Manage the "Open List": If you hit a dead end, go back to the last junction where you had another "candidate" square with a low score and continue from there.

Pro Tip: A* is optimal because it never overestimates the distance. It’s a perfect balance between experience (distance covered) and vision (distance remaining).
